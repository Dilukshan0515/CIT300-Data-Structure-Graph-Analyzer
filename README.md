# CIT300 - Data Structure & Graph Analyzer

A Java project for analyzing and visualizing data structures and graphs.

## Project Structure

```
CIT300-Data-Structure-Graph-Analyzer/
│
├── src/
│   ├── Main.java
│   ├── ArrayModule.java
│   ├── SearchModule.java
│   ├── StackModule.java
│   ├── QueueModule.java
│   ├── LinkedListModule.java
│   └── GraphModule.java
│
├── docs/
│
├── .gitignore
└── README.md
```

## Running the Application

Compile and run `src/Main.java`:
```bash
javac src/Main.java -d bin
java -cp bin Main
```
